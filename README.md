# SoniVoice Website

Marketing site for **SoniVoice** — the AI phone receptionist for every business.

**How it works:** if you don't answer in 3 rings, the AI picks up, handles the call like a human (takes restaurant orders, qualifies auto-dealer leads, books home-service jobs), then emails you a summary with the voice recording.

- `index.html` — the full site (open it in a browser, or enable GitHub Pages)
- `assets/images-1.js`, `images-2.js`, `images-3.js` — site images, stored as
  base64 data URIs in JS (they load via `window.__img()` in `index.html`).
  To swap an image, replace the data URI in the matching file.
